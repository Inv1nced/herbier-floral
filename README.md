# Гербарий

Одностраничное портфолио флориста. В коллекции восемь фотографий букетов из исходной папки. «Гербарий», названия работ и текст об авторе можно заменить своим брендом и описанием.

## Локальный запуск

Требуется Node.js 22.12+ или 24 LTS.

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Как обновить работы и контакты

1. Сохраните фото в `public/assets/bouquets/` в WebP с шириной 160, 480 и 960 пикселей. Имена для девятой работы — `09-160.webp`, `09-480.webp`, `09-960.webp`. Фотографии с прозрачностью лучше всего подходят для эффекта парения.
2. Добавьте название и описание в массив `entries` в `src/works.js`. Порядок элементов определяет порядок фотографий. Большое фото используется в слайдере и полноэкранном просмотре.
3. Для отдельного вырезанного слоя укажите путь в поле `cutout`. Для видео добавьте поле `video: 'assets/bouquets/09.mp4'` к работе. Видео запускается без звука и повторяется. При ограничении движения используется фото.
4. Заполните `contacts.instagram`, `contacts.tiktok` полными URL и `contacts.email` адресом почты. Заполненные кнопки появятся в подвале и в углу экрана.
5. Название, текст и фото обложки, а также метаданные для превью ссылки меняются в `index.html`. Для нового домена также обновите `og:url` и `og:image`.

## Публикация

GitHub Pages публикует корень ветки `gh-pages`. Чтобы обновить сайт после изменений в `main`, соберите проект и отправьте новую сборку в эту ветку.

```sh
npm run build
npx gh-pages --dotfiles -d dist
```

В настройках **Settings → Pages** источник — **Deploy from a branch**, ветка `gh-pages`, папка `/ (root)`. Папка `dist/` подходит и для другого статического хостинга.
